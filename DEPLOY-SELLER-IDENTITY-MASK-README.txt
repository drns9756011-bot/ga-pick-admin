픽견적 노출용 판매자 정보 공개 정책 수정본

적용 내용
1. 고객이 제안을 선택하기 전에는 판매 채널만 그대로 표시합니다.
2. 선택 전 지점명과 매니저명은 마스킹합니다.
3. 선택 전 연락처와 명함 이미지는 서버 응답에서도 제거합니다.
4. 고객이 선택한 제안의 매니저만 지점명, 매니저명, 직책, 연락처, 명함을 공개합니다.
5. 기존 견적과 신규 견적 모두 같은 표시 정책이 즉시 적용됩니다.
6. 관리자 토큰으로 조회하는 관리자 API 응답은 원본 정보를 유지합니다.

배포 대상
- Cloudflare 노출용 프로젝트 ga-pick.com
- 관리자용 프로젝트에 업로드하지 마세요.
