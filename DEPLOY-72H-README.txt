픽견적 노출용 72시간 견적 정책 적용본

적용 내용
1. 신규 견적 제안 가능 시간: 등록 시각 기준 72시간
2. 기존 진행 중 견적: 배포 후 최초 API 호출 시 등록 시각 + 72시간으로 자동 변경
3. 기존 48시간 자동마감 견적 중 새 72시간 만료 전인 건: 자동으로 진행 상태 복구
4. 고객 조기 종료 및 제안 선택 종료: 기존대로 유지하며 다시 열지 않음
5. 고객/판매자 화면 남은 시간: 일·시간·분·초 단위로 1초마다 갱신

배포
Cloudflare 노출용 프로젝트(ga-pick.com)에 이 ZIP 전체를 배포합니다.
관리자용 ZIP도 이어서 배포하면 관리자 화면에서도 초 단위 남은 시간이 표시됩니다.
