픽견적 노출용 전체 라이트 테마 고정 V15

적용 범위
- /
- /quote
- /my-quote
- /seller
- /seller/register
- /brand

적용 내용
- iOS Safari 포함 시스템 다크모드에서 픽견적 UI를 라이트 테마로 유지
- meta color-scheme=light
- Safari 호환 supported-color-schemes=light
- PWA/홈화면 상태바 default
- CSS color-scheme: only light
- input/select/textarea/button 등 네이티브 폼 컨트롤도 라이트 고정
- site.webmanifest의 background_color=#ffffff 유지 확인

관리자용에는 적용하지 않음.
