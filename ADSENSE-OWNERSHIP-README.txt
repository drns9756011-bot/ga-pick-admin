적용 페이지:
- /
- /quote
- /my-quote
- /brand
- /seller
- /seller/register

각 페이지의 <head> 안에 아래 AdSense 스크립트를 1회씩 삽입했습니다.
관리자용 프로젝트에는 적용하지 않았습니다.

배포 대상: 노출용 ga-pick-public Cloudflare 프로젝트
배포 후 Google AdSense에서 "코드를 삽입했습니다" 체크 → 확인을 진행하세요.
