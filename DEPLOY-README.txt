픽견적 노출용 방문자 집계 적용본

배포 대상: ga-pick.com 노출용 Cloudflare 프로젝트

적용 내용
1. 실제 브라우저 방문을 날짜별 익명 해시로 집계합니다.
2. 원본 IP와 개인정보는 저장하지 않습니다.
3. 같은 방문자의 동일 페이지 반복 호출은 30분 안에는 중복 조회로 집계하지 않습니다.
4. site_visit_daily / site_visit_uniques / site_visit_events 테이블은 최초 호출 시 자동 생성됩니다.

주의
- 방문 통계는 이 배포본을 올린 시점부터 집계됩니다.
- 과거 방문 기록은 소급 복구되지 않습니다.
- 관리자용과 동일한 D1 DB(ga-pick-db)를 사용해야 합니다.
