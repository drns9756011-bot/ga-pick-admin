픽견적 브랜드관 V5 - 공개 채널명 전용 노출

공개 /brand 화면 정책
- 지점명 비노출
- 매니저명 비노출
- 지점 지역 비노출
- 공개 API /api/brand-packages에서도 지점/매니저/지역 필드 제거
- 공개 채널명은 다음 4개로 표준화
  1) 전자랜드
  2) 하이마트
  3) 삼성스토어
  4) LG전자 BEST SHOP
- 패키지 카드, 추천 카드, 상담 모달에는 채널명만 표시
- 상담 신청은 package_id/seller_id를 통해 실제 등록 판매자에게 내부 전달
- 판매자 관리 /brand/manage에서는 본인 관리 목적의 실제 정보 유지
